Isolated XFOIL Worker Architecture

Separation of concerns with a secure, policy-controlled solver backend.
1. Streamlit / Desktop UI
Handles study definition, visualization, validation, and downloads. Strictly prohibits arbitrary user command execution.
2. XFOIL Adapter
Uses allowlisted batch commands, shell=False, independent temporary directory isolation, strict timeouts, and structured manifest failures.
3. FastAPI Worker
Enforces fail-closed API key auth, body size limits, per-credential quotas, semaphore concurrency, and exposes /healthz and /readyz probes.
4. Container / Kubernetes
Executes as non-root (UID 10001) with a read-only filesystem, drops ALL capabilities, and restricts network egress to DNS only.
