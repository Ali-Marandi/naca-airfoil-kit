Testable Security Policies

Automated validation of network boundaries, readiness, and resilience.
Security Control
Automated Evidence / Test Coverage
Auth & Readiness
Fail-closed design: Missing secret rejects polar API with 503 and readiness probe with 503.
Runtime Limits
Static manifest tests assert non-root, readOnlyRootFilesystem, seccomp RuntimeDefault, and cap drop ALL.
Network Boundary
Ingress restricted to labeled namespace/pod. Egress restricted to kube-dns. Verified via static YAML tests.
Resilience Regression
Unit tests cover subprocess timeout, OSError, missing executable, per-credential quota, and body-size boundaries.
In-Cluster Validation
Runner script verifies 5 consecutive health calls, readiness, DNS egress, and explicitly denies unlabeled callers.
Static tests guarantee policy source correctness. In-cluster validation proves the CNI actually enforces the policy. A NetworkPolicy without a CNI enforcing it is just a YAML file.
